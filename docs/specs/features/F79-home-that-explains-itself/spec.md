# Feature F79: A Home que se explica, para montar uma série
**Approved**: pendente

## Summary
**A feature:** A seção inicial do site, onde se monta uma série de álbuns, redesenhada no texto, nos elementos e no fluxo.

**Por quê:** A tela de hoje fala em nomes de código e não diz o que é uma série nem para que ela serve.

**Como saber que funcionou:** A escrever com o protótipo: quem nunca viu a tela monta uma série sem ajuda.

## Problem Statement
Dito pelo MJRP em 2026-11-20, com uma captura da Home: «vamos utilizar as skills de UI e UX e de writing copy para melhorar essa seção inicial do site … Gostaria de ver uma proposta consolidar, elevar, transformar, considerando copy, elementos de UI e UX e usabilidade.»
