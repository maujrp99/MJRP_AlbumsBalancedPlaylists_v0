# S-73 · Como quem começa uma série, quero que a tela de montar série se chame «Criar» e tenha um ícone de adição, para que o nome diga o que a tela faz.

## pt-BR

Origem: o MJRP, em 2026-11-22: «O que acha de mudar o start para Crie/Create ? E ao invés de um ícone de go seja algo relacionado a adição?» É uma pergunta, ainda não uma decisão: o orquestrador respondeu que concorda (o verbo diz o que a tela faz; um sinal de mais como ícone). O MJRP confirma o nome e o ícone.
Hoje o item do menu e a aba do celular se chamam «Start» («Inicie»), com o ícone «Go» (F85, F88). A F91 registra o pedido.

## en

**As someone who starts a series, I want the build-a-series screen to be called «Create» with an add icon, so that the name says what the screen does.**

Origin: the MJRP's question of 2026-11-22 (above); not yet decided by him.
