# NFR-02 · O desempenho do app é medido com o Lighthouse

## pt-BR

O desempenho do app é auditado com o Lighthouse a cada versão que vai para produção, e o resultado fica registrado. A nota mínima e as telas medidas: a perguntar ao MJRP (pergunta P-18 do relatório do pacote C1).
Vale para: todas as features · conferida na revisão, com a `constitution.md`
Origem: `docs/ROADMAP.md:13-16` (Sprint 24: «Performance Audit (Lighthouse)»); PRD, Candidatos. A documentação não diz nota nem tela.

## en

**The app's performance is measured with Lighthouse**

The app's performance is audited with Lighthouse on every version that goes to production, and the result is recorded. The minimum score and the screens measured: to ask the MJRP (question P-18 of the package C1 report).
Applies to: all features · checked in review, with `constitution.md`
Origin: `docs/ROADMAP.md:13-16` (Sprint 24: “Performance Audit (Lighthouse)”); PRD, Candidates. The documentation gives no score and no screen.
